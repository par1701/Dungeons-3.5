# Mystic Theurge
*Fuente: Core Rulebooks*

## Requisitos
- Habilidades: Conocimiento (arcano) 6 rangos, Conocimiento (religión) 6 rangos.
- Conjuros: capacidad de lanzar conjuros divinos de nivel 2 y conjuros arcanos de nivel 2.

## Dado de golpe / Habilidades de clase
- Dado de golpe: d4.
- Habilidades de clase: Concentración (Con), Oficio (Int), Descifrar escritura (Int), Conocimiento (arcano/religión) (Int), Profesión (Sab), Sentir motivaciones (Sab), Conjuración (Int).
- Puntos de habilidad por nivel: 2 + modificador de Int.

## Spells per Day
Sin tabla de conjuros propia: cada nivel de esta clase otorga simultáneamente un nivel de progresión en UNA clase arcana previa y UNA clase divina previa que ya poseía (sin otros beneficios de esas clases); si tenía varias clases arcanas o divinas, debe elegir a cuál asigna cada nivel.
