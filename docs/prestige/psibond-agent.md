# Psibond Agent
*Fuente: Complete Scoundrel*

## Requisitos
- Habilidades: Obtener Información 8 rangos, Sentir Motivaciones 4 rangos
- Idiomas: tres cualesquiera
- Psiónica: reserva de puntos de poder de al menos 1
- Especial: ataque furtivo +1d6

## Dado de golpe / Habilidades de clase
- Dado de golpe: d6
- Habilidades de clase: Tasar (Int), Equilibrio (Des), Farsear (Car), Trepar (Fue), Concentración (Con), Oficio (Int), Descifrar Escritura (Int), Diplomacia (Car), Inutilizar Mecanismo (Int), Disfrazarse (Car), Escapismo (Des), Falsificación (Int), Obtener Información (Car), Ocultarse (Des), Intimidar (Car), Saltar (Fue), Conocimientos (local) (Int), Escuchar (Sab), Moverse Sigilosamente (Des), Abrir Cerraduras (Des), Interpretar (Car), Profesión (Sab), Búsqueda (Int), Sentir Motivaciones (Sab), Juego de Manos (Des), Hablar Idioma (ninguna), Avistar (Sab), Nadar (Fue), Piruetas (Des), Usar Objetos Psiónicos (Car), Usar Cuerdas (Des)
- Puntos de habilidad por nivel: 6 + mod. Int

## Rasgos de clase
- **Vínculo psíquico / Psibond (Sob):** Requiere estar enfocado psiónicamente para establecerlo (acción estándar); un sujeto no dispuesto hace salvación de Voluntad (CD 10 + nivel de clase + mod. Car). Dura mientras se concentre, hasta 1 minuto/nivel; alcance de establecimiento 100 pies, pero persiste aunque el sujeto se aleje (se suspende si cambia de plano). Otorga habilidades progresivas según el nivel:
  - *Enlace sensorial forzado* (nivel 1): como acción rápida, percibe uno de los sentidos (vista, oído, gusto u olfato) del sujeto; usa las habilidades del sujeto para pruebas de percepción; pierde su bono de Destreza a la CA mientras lo usa.
  - *Empujón* (nivel 2): como acción inmediata, implanta una sugerencia sutil sobre qué elección tomar el sujeto ante una decisión (sin especificar acción concreta); sin salvación, pero falla si la acción implica peligro obvio; solo una vez por vínculo.
  - *Empatía* (nivel 4): detecta emociones superficiales del sujeto como acción gratuita; +2 de intuición en Farsear/Diplomacia/Intimidar/Sentir Motivaciones contra ese sujeto mientras dure el vínculo.
  - *Sugestión* (nivel 6): como acción rápida, usa sugestión (como el conjuro) sobre el sujeto; Voluntad CD 13 + mod. Car; una vez por vínculo.
  - *Entrada sensorial falsa* (nivel 8): como acción rápida cada asalto, falsea uno de los sentidos del sujeto (sin salvación).
  - *Dominar* (nivel 10): acción estándar; como el conjuro dominar monstruo; Voluntad CD 19 + mod. Car; dura 1 hora si tiene éxito; termina automáticamente el vínculo.
- **Ataque furtivo (Ex):** +1d6 desde nivel 3, +2d6 desde nivel 6, +3d6 desde nivel 9; se acumula con ataque furtivo de otras fuentes.
- **Vínculo psíquico persistente (Sob, nivel 5):** El vínculo permanece 1 asalto tras dejar de concentrarse; si retoma la concentración al asalto siguiente, no se pierde el efecto.
- **Doble vínculo psíquico (Sob, nivel 7):** Puede mantener dos vínculos psíquicos simultáneos con sujetos distintos; las habilidades especiales deben usarse por separado para cada uno.
