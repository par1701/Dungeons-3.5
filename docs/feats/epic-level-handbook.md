# Feats - Epic Level Handbook
*Fuente: Epic Level Handbook*

Las dotes épicas se ganan a nivel 21 y cada 3 niveles después, en lugar de una dote normal (además de las dotes épicas de bonificación que otorgan algunas clases). Un prerequisito numérico es un mínimo. Tipos especiales: **Divina** (requiere poder expulsar/reprender no-muertos; cada uso gasta un intento diario de expulsión), **Salvaje** (requiere la capacidad de forma salvaje), **Psiónica Épica** (versión psiónica, traducida de la mecánica arcana equivalente).
