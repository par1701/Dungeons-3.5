# Legendary Dreadnought
*Fuente: Epic Level Handbook*

## Requisitos
- BAB: +23
- Habilidades: Intimidate 15 rangos
- Dotes: Combat Reflexes, Great Cleave, Improved Bull Rush, Improved Critical

## Dado de golpe / Habilidades de clase
- Dado de golpe: d12
- Puntos de habilidad por nivel: 2 + mod. Int
- Habilidades de clase: Climb, Craft, Intimidate, Jump, Swim

## Rasgos de clase
**Competencia con armas y armaduras:** competente con armas simples y marciales, toda armadura y escudos.

**Unstoppable (Ex):** +20 a una prueba de Fuerza para romper/derribar una puerta u objeto (también aplicable a romper un wall of force, CD 32, o a una sola tirada de ataque); 1/día desde nivel 1, +1 uso cada cinco niveles.

**Unmovable (Ex):** +20 a una de las siguientes: prueba de agarre para evitar ser sujetado, prueba de Fuerza contra un embate/derribo o efecto similar, prueba de Fuerza contra un desplazamiento físico/mágico, o una salvación (otorgando una de Voluntad si el efecto normalmente no permite salvación); 1/día desde nivel 2, +1 uso cada cinco niveles.

**Shrug off Punishment (Ex):** 12 puntos de golpe extra a nivel 3, y otros 12 cada cinco niveles después.

**Thick Skinned (Ex):** reducción de daño 3/- desde nivel 4 (no se acumula con RD de objetos mágicos o efectos temporales, sí con la de efectos permanentes, dotes o esta misma habilidad); mejora +3 cada cinco niveles.

**Dote de bonificación:** en nivel 5 y cada cinco niveles después, de una lista fija de dotes épicas de combate.
