# Guardian Paramount
*Fuente: Epic Level Handbook*

## Requisitos
- BAB: +15
- Habilidades: Spot 13 rangos
- Dotes: Alertness, Lightning Reflexes
- Dotes épicas: Blinding Speed, Superior Initiative
- Especial: poseer uncanny dodge y evasion

## Dado de golpe / Habilidades de clase
- Dado de golpe: d10
- Puntos de habilidad por nivel: 4 + mod. Int
- Habilidades de clase: Bluff, Climb, Diplomacy, Intimidate, Jump, Listen, Profession, Spot

## Rasgos de clase
**Competencia con armas y armaduras:** competente con armas simples y marciales, toda armadura y escudos.

**Dotes de bonificación:** en nivel 1 y cada tres niveles después, de una lista fija de dotes épicas defensivas.

**Habilitador de uncanny dodge (Ex):** extiende su propio uncanny dodge (conservar Destreza en CA aunque esté desprevenido o ante atacantes invisibles) a una criatura designada a 5 pies; 3/día desde nivel 1, +1 uso cada tres niveles.

**Preceptor evasivo (Ex):** extiende su evasion (o improved evasion) a una criatura designada a 5 pies; 1/día desde nivel 2, +1 uso cada tres niveles.

**Aura protectora (Sp):** desde nivel 3, versión de shield other (lanzador nivel 8) donde el daño transferido llega como daño no letal al paramount; 1/día, +1 uso cada tres niveles.

**Ajustar probabilidad (Ex):** desde nivel 5, obliga a repetir una tirada de ataque, prueba o salvación de una criatura en 25 pies (puede ver el resultado antes de decidir); 2/día, +1 uso cada tres niveles; no puede usarse si está desprevenido o no puede ver la situación.

**Traer de vuelta (Sp):** desde nivel 6, resucita (true resurrection, lanzador nivel 20) a una criatura que haya protegido antes con sus otras habilidades; 1/día, +1 uso cada seis niveles.
