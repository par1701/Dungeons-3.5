# Eldritch Knight
*Fuente: Core Rulebooks*

## Requisitos
- Competencia con armas: debe ser competente con todas las armas marciales.
- Conjuros: capacidad de lanzar conjuros arcanos de nivel 3.

## Dado de golpe / Habilidades de clase
- Dado de golpe: d6.
- Habilidades de clase: Concentración (Con), Oficio (Int), Descifrar escritura (Int), Saltar (Fue), Conocimiento (arcano / nobleza y realeza) (Int), Montar (Des), Sentir motivaciones (Sab), Conjuración (Int), Nadar (Fue).
- Puntos de habilidad por nivel: 2 + modificador de Int.

## Spells per Day
Sin tabla propia: desde el nivel 2, cada nivel de esta clase otorga conjuros por día como si hubiera subido un nivel en la clase arcana lanzadora que ya poseía, sin otros beneficios de esa clase; si tenía varias clases arcanas, debe elegir a cuál asigna cada nivel.

## Rasgos de clase
- **Competencia con armas y armaduras**: ninguna competencia adicional.
- **Dote de bonificación**: en nivel 1, elige una dote adicional de la lista disponible para guerreros (debe cumplir los prerrequisitos, incluidos niveles de guerrero para dotes como Especialización en arma).
- **Conjuros por día**: ver arriba.
