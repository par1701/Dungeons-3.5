# Objetos Mágicos - Pergaminos, Bastones y Varitas

Fuente: https://srd.dndtools.org/srd/equipment/magicItemsSSW.html (SRD 3.5, "Magic Scrolls, Staffs, and Wands")

## Pergaminos (Scrolls) - Reglas completas

**Naturaleza:** Un pergamino almacena un hechizo (o varios) por escrito; cada hechizo se usa una sola vez y el texto desaparece al activarse. Estadísticas físicas del objeto: CA 9, 1 pg, dureza 0, CD de rotura 8.

**Descifrar el texto:** Antes de usar o identificar el contenido, requiere el conjuro *read magic* o una prueba de Conjuración (Spellcraft) CD 20 + nivel del hechizo. Descifrar no activa la magia (salvo pergaminos malditos especialmente preparados).

**Activar el hechizo:** Requiere leer el pergamino en voz alta y poder ver/leer el texto. No requiere componentes materiales ni foco (los aportó el creador). Si el hechizo solo afecta objetos, el usuario debe proveer el objeto. La activación puede ser interrumpida igual que lanzar un conjuro normal, y cuenta como lanzar un conjuro a efectos de probabilidad de fallo de conjuro arcano por armadura.

**Requisitos para activar un hechizo de pergamino:**
1. El conjuro debe ser del tipo correcto (arcano o divino) para la clase del usuario: lanzadores arcanos (mago, hechicero, bardo) solo pueden usar pergaminos arcanos; lanzadores divinos (clérigo, druida, paladín, explorador) solo pergaminos divinos.
2. El usuario debe tener el conjuro en la lista de conjuros de su clase.
3. El usuario debe tener la puntuación de característica necesaria.

Si se cumplen los tres requisitos y el nivel de conjurador del usuario es ≥ nivel de conjurador del pergamino, el conjuro se activa automáticamente sin prueba. Si el nivel de conjurador del usuario es menor, debe superar una prueba de nivel de conjurador (CD = nivel de conjurador del pergamino + 1); si falla, debe superar una prueba de Sabiduría CD 5 para evitar un percance (un 1 natural siempre falla, sin importar modificadores).

**Efecto:** Un hechizo activado desde un pergamino funciona igual que preparado y lanzado normalmente. Se asume que el nivel de conjurador del pergamino es el mínimo necesario para lanzar ese conjuro (normalmente el doble del nivel del conjuro, menos 1), salvo que el creador desee otra cosa.

**Percances de pergamino (tabla de efectos posibles al fallar):** 1) descarga de energía mágica: 1d6 puntos de daño por nivel de conjuro al usuario; 2) el conjuro golpea al usuario o a un aliado (o un objetivo aleatorio cercano) en vez del objetivo previsto; 3) el conjuro surte efecto en un lugar aleatorio dentro del alcance; 4) el efecto es contrario al normal; 5) el usuario sufre un efecto menor pero extraño relacionado con el conjuro (duración = la del conjuro, o 2d10 minutos si es instantáneo); 6) aparece algún objeto inocuo en el área; 7) efecto retardado: se activa en 1d12 horas, dirigido al receptor original si se ha movido.

**Tipos de pergamino (tirada d%):** 01–70 Arcano, 71–100 Divino.

**Número de hechizos por pergamino:** Menor 1d3 conjuros; Mediano 1d4 conjuros; Mayor 1d6 conjuros.

**Nivel de conjurador según nivel de conjuro (para pergaminos menor/mediano/mayor):**
| Nivel de conjuro | Nivel de conjurador del hechizo |
|---|---|
| 0 | 1 |
| 1º | 1 |
| 2º | 3 |
| 3º | 5 |
| 4º | 7 |
| 5º | 9 |
| 6º | 11 |
| 7º | 13 |
| 8º | 15 |
| 9º | 17 |

**Fórmula de precio (verificada contra la tabla de precios del SRD):** Precio = nivel de conjuro × nivel de conjurador × 25 po (el nivel 0 cuenta como 1/2). Ejemplos verificados: 1º nivel (NC1) = 25 po; 2º nivel (NC3) = 150 po; 3º (NC5) = 375 po; 4º (NC7) = 700 po; 5º (NC9) = 1.125 po; 6º (NC11) = 1.650 po; 7º (NC13) = 2.275 po; 8º (NC15) = 3.000 po; 9º (NC17) = 3.825 po; nivel 0 (NC1, ×1/2) = 12 po 5 pp. Algunos conjuros individuales tienen precio mayor al listado porque en el SRD aparecen tabulados con un nivel de conjurador superior al mínimo (variantes "reforzadas"); el precio de cada conjuro concreto sigue la misma fórmula con su propio nivel de conjurador efectivo.

**Reglas adicionales:** Muchos conjuros arcanos varían de nivel entre hechicero/mago (nivel por defecto usado en la tabla) y bardo. Muchos conjuros divinos varían entre clérigo/druida (nivel por defecto) y paladín/explorador. Conjuros que son arcanos o divinos según la clase aparecen en ambas listas al nivel correspondiente.

## Bastones (Staffs) - Reglas generales

**Naturaleza:** Vara larga que almacena varios hechizos, todos de una temática fija (a diferencia de las varitas). Tiene 50 cargas al crearse. Estadísticas físicas: CA 7, 10 pg, dureza 5, CD de rotura 24.

**Activación:** Usa el método de activación por "disparo de conjuro" (spell trigger): normalmente es una acción estándar que no provoca ataque de oportunidad (salvo que el conjuro almacenado tenga un tiempo de lanzamiento mayor a 1 acción estándar, en cuyo caso tarda ese tiempo). El usuario debe sostener el bastón al frente con al menos una mano.

**Cualidades especiales:** Tirada d%: 01–30 indica que algún diseño/inscripción da una pista sobre la función del bastón; 31–100 indica que no hay pistas especiales.

**Regla clave de nivel de conjurador:** El bastón usa la puntuación de característica y dotes del portador para fijar la CD de salvación de sus conjuros (no las del creador). El portador puede usar su propio nivel de conjurador si es mayor que el nivel de conjurador del bastón — esto hace que los bastones sean más potentes en manos de conjuradores poderosos (mayor alcance/duración, más difícil de anular y mayor probabilidad de superar resistencia a conjuros). Un bastón puede almacenar un conjuro de cualquier nivel (a diferencia de las varitas, limitadas a nivel 4 o menos). El nivel de conjurador mínimo de un bastón es 8º.

**Nota sobre recarga:** La página fuente no detalla explícitamente el procedimiento de recarga de bastones (a diferencia de wands, que no se recargan); no se reproduce contenido que no está en la fuente consultada — ver nota de brecha al final.

## Varitas (Wands) - Reglas completas

**Naturaleza:** Bastón corto que contiene un único conjuro de nivel 4 o inferior. Tiene 50 cargas al crearse; cada carga gastada permite usar el conjuro una vez. Sin cargas, es un simple palo. Estadísticas físicas: CA 7, 5 pg, dureza 5, CD de rotura 16.

**Activación:** Método de "disparo de conjuro" (spell trigger): normalmente acción estándar que no provoca ataque de oportunidad (salvo que el conjuro tenga tiempo de lanzamiento mayor a 1 acción, en cuyo caso tarda ese tiempo). El usuario debe sostener la varita en la mano y apuntarla hacia el objetivo o área. Puede usarse mientras se está forcejeando (grapple) o tragado entero.

**Cualidades especiales:** Tirada d%: 01–30 = alguna pista sobre su función; 31–100 = sin pistas.

**Fórmula de precio (verificada contra la tabla de precios del SRD):** Precio = nivel de conjuro × nivel de conjurador × 750 po (el nivel 0 cuenta como 1/2). Ejemplos verificados: *detect magic* (nivel 0, NC1) = 375 po; *magic missile* nivel 1 a NC1 = 750 po, a NC3 = 2.250 po, a NC5 = 3.750 po, a NC7 = 5.250 po, a NC9 = 6.750 po (mismo conjuro de nivel 1, coste creciente solo por mayor nivel de conjurador — variantes de mayor alcance/daño); *bull's strength* (nivel 2, NC3) = 4.500 po; *cure serious wounds* (nivel 3, NC5) = 11.250 po; *cure critical wounds* (nivel 4, NC7) = 21.000 po.

**Uso por no lanzadores de la clase correspondiente:** No se detalla explícitamente en esta página, pero conforme a la regla estándar SRD, un personaje sin el conjuro en la lista de su clase puede usar Utilizar Objetos Mágicos (Use Magic Device) para activar la varita.

**Ejemplos de precios especiales:** Varita de *restoration* = 26.000 po (coste de creación 10.500 po + 840 PX + 5.000 po en componentes materiales). Varita de *stoneskin* = 33.500 po (coste de creación 10.500 po + 840 PX + 12.500 po en componentes materiales).

**Descripciones:** El SRD indica que las varitas no tienen descripciones especiales propias: remiten a la descripción del conjuro almacenado para todos los detalles pertinentes. No se listan varitas individuales con reglas propias más allá del conjuro que contienen (hay, en potencia, una varita para cada conjuro de nivel 0 a 4).

- La página no detalla explícitamente la regla de Utilizar Objetos Mágicos (Use Magic Device) para varitas fuera de la lista de la clase; se indicó como inferencia de la regla estándar SRD, marcada como tal en el texto.
- Los pergaminos y varitas no tienen una lista de "ejemplos" individuales en esta página más allá de las tablas de precios por d%/conjuro — se han verificado y reproducido las fórmulas de precio contrastándolas matemáticamente contra múltiples entradas de esas tablas.
