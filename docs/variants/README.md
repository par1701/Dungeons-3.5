# Clases Variantes D&D 3.5 (SRD) - Indice

Referencia extraida de srd.dndtools.org. Un archivo Markdown por clase (42 archivos), cada uno con el texto completo de esa clase base y TODAS sus variantes, rasgos de clase alternativos y niveles de sustitucion.

## Como usar esto con Claude Code

- Para buscar una variante concreta: `grep -ril "nombre de la variante" .`
- Cada archivo `<clase>.md` contiene todo el contenido de esa clase; leelo entero o busca dentro con grep/offset.
- Este README indica, para cada libro de origen, que variantes aporto y en que archivo de clase esta cada una.
